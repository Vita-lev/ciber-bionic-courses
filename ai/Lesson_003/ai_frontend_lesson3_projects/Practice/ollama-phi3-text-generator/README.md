# Генератор тексту з Ollama (phi3) — HTML/CSS/JS

Веб-застосунок для генерації тексту за допомогою локальної моделі Ollama `phi3`.

## Передумови
- Встановлена Ollama (`https://ollama.ai`)
- Запущений сервер: `ollama serve`
- Завантажена модель: `ollama pull phi3`

## Запуск

**Важливо:** Через обмеження CORS потрібно запускати через локальний веб-сервер, а не відкривати `index.html` напряму.

Введіть запит і натисніть «Згенерувати». Відповідь транслюється у реальному часі.

## Параметри

API URL та назву моделі можна змінити у верхній панелі:
- API URL: `http://localhost:11434/api/generate`
- Модель: `phi3`

## Структура
```
ollama-phi3-text-generator/
├── index.html
└── script.js
```

## Примітки
- Ендпоінт `/api/generate` повертає NDJSON потік; інтерфейс обробляє його построчно.
- Для інших моделей — змініть поле «Модель».
